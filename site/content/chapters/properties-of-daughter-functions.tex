%% title: Basic Properties of Daughter Functions
%% category: properties

Daughter functions take in a tree where left and right daughters have been valued, and modify the features of left nodes somehow. 

There are two hypotheses for daughter functions:

1. \textbf{The Mother-Sharing Hypothesis}
After the mother function has run, if a left node is still unvalued for feature X, and its mother is valued for that feature, then value the left node with the mother's value. 

2. \textbf{The Maximal Projection Sharing}






It is an open question whether daughter functions can actually be thought of as parts of the mother function. If it is only left nodes' mothers which can influence their features, then mother and daughter functions could be combined into a single transition function which takes in a left and a right daughter, and outputs a left daughter with updated features, and a new mother node. 

If Spec-to-Head agreement truly exists, then either this is not the case, or we have to say something more interesting about maximal and minimal projections.
