\section{Basic properties of mother functions}

Mother functions take in a left node and a right node, and output a mother node. Two basic properties of mother functions are farsight and commutativity:

1. \textbf{Farsighted}. The mother function can refer to the feature values of nodes dominated by the two nodes it is computing the mother of, by reaching through their left/right pointers. 
2. \textbf{Commutative}. The mother function cannot see which inputted node is the left node, and which is the right one. 

Note also that commutativity is a gradient property with two endpoints: mother functions can be fully commutative, fully \textbf{anticommutative} (meaning either the left or right daughter always wins), or somewhere in between. 

I will argue strongly that the mother function is likely not farsighted nor commutative. Thus, it can actually be thought of as a function which takes an ordered pair (left, right), where left and right refer to value dictionaries, and returns a new value dictionary. I also suspect that the mother function is not anticommutative.

\section{Basic properties of daughter functions}

Daughter functions take in a tree where left and right daughters have been valued, and modify the features of left nodes somehow. 

There are two hypotheses for daughter functions:

1. \textbf{The Mother-Sharing Hypothesis}
After the mother function has run, if a left node is still unvalued for feature X, and its mother is valued for that feature, then value the left node with the mother's value. 

2. \textbf{The Maximal Projection Sharing}






It is an open question whether daughter functions can actually be thought of as parts of the mother function. If it is only left nodes' mothers which can influence their features, then mother and daughter functions could be combined into a single transition function which takes in a left and a right daughter, and outputs a left daughter with updated features, and a new mother node. 

If Spec-to-Head agreement truly exists, then either this is not the case, or we have to say something more interesting about maximal and minimal projections.
