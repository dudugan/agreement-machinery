%% title: Labelling Algorithms
%% category: definitions

A \textbf{labelling algorithm} is a function that takes in a tree whose left nodes are decorated with inherent features, and outputs a tree whose right nodes are decorated with features too, and whose left nodes may have different features from the ones they started out with.

We can represent the input tree as a list of left nodes, ordered by merge step: first the first two items in the list are merged, then the next item is merged with the result, then the next, and so on. The lowest left node is the first element. Since the lexical root doesn't impact its mother's features, that mother has the same features as the lowest left node, so the next element in the list is simply the second-lowest left node.

The output tree can also be represented as a list of nodes ordered by merge step, but it is longer, because by this point the right nodes have been valued too.

\section{Mother and daughter functions}

Each labelling algorithm needs two sub-algorithms:

\begin{description}
  \item[The mother function] takes in a left node and a right node, and computes their mother node.
  \item[The daughter function] modifies the features of left nodes in the tree, after the mother function has run over it.
\end{description}

It might seem odd that the daughter function is necessary at all. Once the mother function has run recursively over every element, all of the nodes in the tree, left and right, have feature values.

However, if this were the finished tree, agreement would never occur. The left nodes and the lexical root are the only nodes that are actually pronounced, and their feature values would be exactly the ones they started with. What agreement does is allow some left nodes to influence the features of other left nodes: to \textit{change} their values.

Crucially, in this framework, for one left node to change the values of another, it needs to recursively change the values of every right node on the shortest path between them. This is what the mother function does. The daughter function then allows right nodes to influence their daughters, which is what finally changes the values of left nodes.

\section{Properties of labelling algorithms}

To specify a labelling algorithm, then, one needs to specify three things:

\begin{enumerate}
  \item properties of the algorithm itself,
  \item properties of the mother function, and
  \item properties of the daughter function.
\end{enumerate}
